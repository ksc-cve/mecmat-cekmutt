# mecmat-cekmutt

เว็บของกลุ่มวิจัย **MECMAT — Mechanics and Materials Research Group**
ภาควิชาวิศวกรรมโยธา คณะวิศวกรรมศาสตร์ มหาวิทยาลัยเทคโนโลยีพระจอมเกล้าธนบุรี

มีสองส่วนที่ใช้ฐานข้อมูลเดียวกัน
- หน้าเว็บประชาสัมพันธ์ (TH/EN)
- หลังบ้านสำหรับบริหารกลุ่ม: บุคลากร ผลงาน โครงการ การเงินเชิงตัวเลข ครุภัณฑ์ การจอง งาน/ประชุม เอกสาร และข่าว

โปรเจกต์นี้แยกจาก Reaction ERP โดยสิ้นเชิง คนละ repo คนละโฟลเดอร์ คนละฐานข้อมูล และคนละชุดสำรองข้อมูล
