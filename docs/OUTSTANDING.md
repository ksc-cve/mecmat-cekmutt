# เรื่องที่ต้องเตือน/ขอจากเจ้าของ

อัปเดต: 2026-10-29

## ต้องให้เจ้าของทำ หรืออนุญาตให้ทำ
- [ ] **ขึ้นเซิร์ฟเวอร์**: ทำตาม [deployment.md](deployment.md)
  - Claude ถูกระบบสิทธิ์ห้ามอ่าน/เขียนเซิร์ฟเวอร์ production จึงยังไม่ได้แตะเครื่อง
  - เจ้าของจะรันเอง หรืออนุญาตให้ Claude รัน `deploy/ship.sh` ก็ได้
- [ ] **ก่อนแก้ Caddy** ต้องตรวจ `caddy version` และดูว่า Caddyfile มีบล็อก catch-all ของ ERP อยู่หรือไม่
- [ ] **ตรวจข้อมูล ดร.กสาน** ที่ seed จากการค้นคว้า และยืนยันบทบาท ก.พ.อ. ของผลงาน 9 รายการ
  - ผู้แต่งลำดับแรกถูกตั้งเป็น "ผู้ประพันธ์อันดับแรก" ไว้ ส่วนผู้ประพันธ์บรรณกิจยังไม่ได้ระบุ
- [ ] **ตำแหน่ง "หัวหน้ากลุ่มวิจัย"** ตั้งเป็น ดร.กสาน ไว้ชั่วคราว แก้ได้ที่ ผู้ดูแลระบบ → โครงสร้างอำนาจ
- [ ] **ตรวจวงเงินอนุมัติเริ่มต้น** (≤5,000 / ≤50,000 / >50,000 บาท) แก้ได้ในหน้าเดียวกัน
- [ ] ข้อความ "เกี่ยวกับเรา" และสาขาวิจัย 4 สาขา เป็นร่างที่ Claude เขียนจากผลงานของ ดร.กสาน กรุณาแก้ในหน้า "เนื้อหาเว็บไซต์"

## ข้อมูลบุคลากรจากการค้นคว้า (2026-10-29) — ให้เจ้าของตรวจ
ที่มาของข้อมูลทั้งหมดอยู่ใน `tools/seed/build_group.py` ถ้าต้องแก้ ให้แก้ที่ไฟล์นี้แล้วรันใหม่ แต่ถ้าระบบใช้งานจริงแล้ว ให้แก้ในหน้าบุคลากรแทน

- **สายที่ปรึกษา/ศิษย์**: ใช้ตามที่ ดร.กสาน บอกเท่านั้น
  - งานค้นคว้าพบ "ศิษย์ที่อนุมานจากการเป็นผู้ร่วมเขียน" อีกหลายคน แต่ไม่ได้ใส่เข้าระบบ
  - ตัวอย่าง: ดร.วีรพันธ์ เจียมมีปรีชา, ดร.ชนะชัย ตั้งบรรจงกิจ และ ดร.มนต์ชัย ปัญญาทอง เป็นศิษย์ ศ.ดร.สมชาย หรือ ผศ.ดร.บุญมี
  - ถ้าต้องการ เพิ่มได้เป็นบุคคลภายนอกพร้อมสายที่ปรึกษา
- **ปีจบการศึกษาที่ยังไม่รู้**: ส่วนใหญ่ไม่มีบนเว็บ
  - รู้แล้ว: ดร.กสาน (วศ.บ. 2558, วศ.ม. 2561, ปร.ด. 2567), รศ.ดร.ชัยณรงค์ (ปร.ด. 2543–2551), รศ.ดร.ทวิช (ปร.ด. ประมาณ 2548)
- **ศ.ดร.สมชาย**: ไม่พบประกาศรางวัลใด ๆ บนเว็บ (เช่น นักวิจัยดีเด่นแห่งชาติ, ราชบัณฑิต) และไม่รู้ปีที่ดำรงตำแหน่งรองอธิการบดีอาวุโส
  - ความร่วมมือกับ Prof. Giuseppe Rega บันทึกเป็น "อิตาลี" โดยไม่ระบุมหาวิทยาลัย เพราะยังยืนยันไม่ได้
- **รศ.ดร.ทวิช**: ตำแหน่งรองคณบดีฝ่ายวิชาการและวิจัยก่อนปี 2567 ยังยืนยันไม่ได้ จึงยังไม่ใส่
- **ดร.วราวิทย์**: ผลงานด้าน BIM ปี 2567–68 ที่สังกัด ม.ธนบุรี อาจเป็นคนเดียวกัน แต่ยังยืนยันไม่ได้ จึงยังไม่ใส่
- **ภูตะวัน ยวนานนท์**: ไม่พบข้อมูลสาธารณะเลย และไม่รู้ชื่อภาษาอังกฤษ
- **ศิษย์เก่าและบุคคลภายนอก** (ดร.วราวิทย์, ภูตะวัน) ยังไม่แสดงบนเว็บไซต์ เพราะหน้าบุคลากรแสดงเฉพาะบุคลากรภายใน
  - ถ้าต้องการหน้า "ศิษย์เก่า" บอกได้
- **ฐานข้อมูลที่ตีพิมพ์** (Scopus/WoS/TCI และ quartile) ของผลงาน 72 เรื่องยังไม่ได้ระบุ เพราะยังไม่ได้ตรวจกับแหล่งจริง

## งานที่ควรทำต่อ (ยังไม่ทำในรอบนี้)
- `tools/uicheck` แบบ ERP (headless Chrome เปิดทุกหน้าทั้งเดสก์ท็อปและมือถือ)
  - รอบนี้ตรวจทุก route ใน Chrome ด้วยมือและใช้ `tools/apicheck/smoke.py` แทน
- QR code สำหรับตั้งค่า Authenticator ตอนนี้ต้องพิมพ์คีย์เอง (หรือเปิดลิงก์ otpauth บนมือถือ) เพราะยังไม่ได้เขียนตัวสร้าง QR และไม่ใช้ไลบรารีภายนอก
- นำเข้าผลงานจาก ORCID ทั้งชุด (ตอนนี้นำเข้าได้ทีละ DOI)
- ตำแหน่งงาน (PositionText) ยังมีภาษาเดียว บนหน้า EN จะแสดงภาษาไทยถ้ากรอกเป็นไทย
