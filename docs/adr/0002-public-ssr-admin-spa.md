# ADR 0002 — หน้าสาธารณะเรนเดอร์ที่เซิร์ฟเวอร์ หลังบ้านเป็น SPA

- สถานะ: ตัดสินแล้ว (2026-10-28)

## บริบท
หน้าเว็บประชาสัมพันธ์ต้องให้ Google และโซเชียลมีเดียอ่านได้ (SEO, OpenGraph) และต้องโหลดเร็วบนมือถือ
ส่วนหลังบ้านเป็นแอปที่มีฟอร์มและตารางจำนวนมาก แบบเดียวกับ ERP

## ตัดสินใจ
- **หน้าสาธารณะใช้ Razor Pages** ซึ่งมีอยู่ใน ASP.NET Core แล้วไม่ต้องเพิ่ม package
  - URL: `/` (ไทย) และ `/en/...` (อังกฤษ)
  - มี sitemap.xml และ OpenGraph ทุกหน้า
  - JavaScript น้อยที่สุด หน้าเว็บต้องใช้งานได้แม้ปิด JS
- **หลังบ้านเป็น SPA** ที่ `/app` (hash router) เรียก `/api/*`
- **ใช้ฐานข้อมูลเดียวกัน** หน้าสาธารณะอ่านเฉพาะระเบียนที่ `Published` และเฉพาะฟิลด์ที่เจ้าของข้อมูลเปิดให้แสดง (ADR 0007) จึงไม่ต้องมีขั้น "ส่งข้อมูลไปหน้าเว็บ"
- โค้ดหน้าสาธารณะ **ไม่เรียก DbContext ตรง** แต่ผ่าน `PublicQueryService` ที่ใส่ตัวกรอง Published/visibility ไว้ที่เดียว เพื่อกันข้อมูลส่วนตัวหลุดเพราะลืมใส่ตัวกรองในบางหน้า

## ผลที่ตามมา
- มีสองวิธีเรนเดอร์ในโปรเจกต์เดียว แต่ใช้ CSS token ชุดเดียวกัน
- การแก้ข้อมูลในหลังบ้านมีผลบนหน้าเว็บทันที
