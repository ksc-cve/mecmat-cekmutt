# ADR 0007 — ข้อมูลส่วนบุคคลและการแสดงผลสาธารณะ (PDPA)

- สถานะ: ตัดสินแล้ว (2026-10-28)

## บริบท
ระบบเก็บเลขบัตรประชาชน บัญชีรับเงิน ประวัติการศึกษา และประวัติการทำงาน เจ้าของสั่งว่า "ข้อมูลที่แสดงสาธารณะให้ User เลือกได้ว่าจะแสดงอะไรบ้าง"
ประกาศความเป็นส่วนตัวของบุคลากร มจธ. ใช้ฐานสัญญาและฐานกฎหมายสำหรับข้อมูลเหล่านี้

## ตัดสินใจ
- **ผู้ใช้เลือกการแสดงผลเองทีละฟิลด์** (`PublicFieldVisibility`)
  - ค่าเริ่มต้นคือแสดงเฉพาะชื่อ ตำแหน่ง ประเภทบุคคล และรูป (ถ้าอัปโหลด) ฟิลด์อื่นซ่อนทั้งหมด
  - รายการประวัติแต่ละรายการ (การศึกษา งาน รางวัล) ก็เลือกซ่อนหรือแสดงได้
- **ฟิลด์ต้องห้าม** คือเลขบัตรประชาชน วันเกิด บัญชีรับเงิน และเบอร์โทรส่วนตัว ฟิลด์เหล่านี้ไม่อยู่ในรายการที่เลือกได้ และ `PublicQueryService` ไม่มีทางอ่านฟิลด์เหล่านี้ได้เลย
- **เข้ารหัสระดับคอลัมน์**ด้วย AES-GCM สำหรับเลขบัตรประชาชน เลขบัญชี พร้อมเพย์ และ TOTP secret กุญแจอยู่ที่ `DataRoot/field.key` (สิทธิ์ 0600) ไม่อยู่ในฐานข้อมูล
  - หน้าจอแสดงแบบปิดบังบางหลัก (เช่น `x-xxxx-xxxxx-12-3`) การกดดูเต็มต้องมีสิทธิ์ และทุกครั้งที่ดูจะบันทึกลง `SensitiveAccessLog`
- **ไม่เก็บข้อมูลอ่อนไหวตามมาตรา 26** (ศาสนา สุขภาพ หมู่เลือด ฯลฯ)
- **แบบฟอร์มสาธารณะ** (ติดต่อเรา, สมัครตำแหน่ง) ต้องมีช่องยินยอมตามนโยบายความเป็นส่วนตัวที่มีเลขเวอร์ชัน เก็บ `ConsentRecord`
  - ใบสมัครที่ไม่ผ่านการคัดเลือกจะถูกลบไฟล์ CV อัตโนมัติหลัง 1 ปี (แก้ใน Settings ได้)
- **ChangeLog** เก็บค่าก่อนและหลังการแก้ไข แต่ไม่เก็บค่าจริงของฟิลด์ที่เข้ารหัส เก็บเพียง "เปลี่ยนแล้ว"
