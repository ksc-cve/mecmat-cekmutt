# ADR 0006 — ใช้ IP ไปก่อนจนกว่าจะมีโดเมน

- สถานะ: ตัดสินแล้ว (2026-10-28) ต้องตรวจเซิร์ฟเวอร์ก่อนลงมือ

## บริบท
เจ้าของสั่งให้ใช้ IP `187.52.127.97` ไปก่อน ซึ่งเป็น VPS เครื่องเดียวกับ Reaction ERP
Caddy เป็นโปรแกรมเดียวที่ถือพอร์ต 80/443 และกำลังให้บริการ reaction-erp.com อยู่

## ตัดสินใจ
- แอปฟังที่ `127.0.0.1:5180` เท่านั้น ห้ามเปิดพอร์ตนี้สู่ภายนอก เพราะรหัสผ่านต้องวิ่งผ่าน HTTPS เสมอ
- เพิ่มบล็อกของเราเพียงบล็อกเดียวใน `/etc/caddy/Caddyfile` ในรูป `187.52.127.97 { ... reverse_proxy 127.0.0.1:5180 }`
- ใบรับรองเลือกตามลำดับดังนี้
  1. ใบรับรอง IP ของ Let's Encrypt แบบอายุสั้น ถ้า Caddy บนเครื่องรองรับ
  2. ถ้าไม่รองรับ ใช้ `tls internal` (เบราว์เซอร์จะเตือน แต่การเชื่อมต่อยังเข้ารหัส)
- **ก่อนลงมือ** ต้องอ่าน Caddyfile และ `caddy version` แบบอ่านอย่างเดียว เพื่อดูว่ามีบล็อกที่ผูก IP หรือ catch-all ของ ERP อยู่แล้วหรือไม่ แล้วรายงานเจ้าของ
- **ทุกครั้งที่แก้**: `caddy validate --config /etc/caddy/Caddyfile` → ได้รับคำยืนยันจากเจ้าของ → `systemctl reload caddy` → ตรวจว่า reaction-erp.com ยังตอบปกติ
- เมื่อได้โดเมนแล้ว เปลี่ยนเฉพาะหัวบล็อก

## ผลที่ตามมา
- ช่วงที่ใช้ IP อาจถูกเตือนเรื่องใบรับรอง และ Google จะไม่ index เว็บ ซึ่งยอมรับได้เพราะยังเป็นช่วงทดลองใช้
